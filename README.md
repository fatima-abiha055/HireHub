# HireHub – Recruitment Management Platform

HireHub is a modern and user-friendly job portal website designed to connect job seekers with career opportunities. It aims to make the job search experience simple, accessible, and convenient through a clean interface and responsive design.

## 🚀 Features

- 💼 Explore job opportunities
- 🔎 Search for relevant jobs
- 👤 User-friendly interface
- 📱 Responsive website design
- ⚡ Fast development and performance with Vite
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layouts
- **JavaScript** – Interactive functionality
- **React.js** – Component-based user interface
- **Vite** – Development server and build tool

## ⚙️ Installation and Setup

Follow these steps to run HireHub locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd hirehub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## 🏗️ Build for Production

To create a production-ready build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
